# Verve CLI — Official Releases

This repository hosts the official binary releases for the Verve Shadow CLI.

## Installation

### macOS (Homebrew)

```bash
brew install gyandeeps/tap/verve-cli
```

### Windows (Scoop)

```powershell
scoop bucket add verve https://github.com/gyandeeps/scoop-verve
scoop install verve-cli
```

### Windows (Direct Download)

Download the latest `verve-cli-windows-amd64.exe` from the [Releases](https://github.com/gyandeeps/verve-releases/releases/latest) page.
